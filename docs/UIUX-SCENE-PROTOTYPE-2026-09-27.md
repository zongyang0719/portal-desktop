# 对话与小镇：第一轮交互预览

> 历史迭代记录。当前设计唯一依据：[IA-REFACTOR-SPEC-2026-09-27.md](IA-REFACTOR-SPEC-2026-09-27.md)；当前实现见 [实施记录](IA-REFACTOR-IMPLEMENTATION-2026-09-27.md)。

2026-09-27。用户在[信息架构校正](UIUX-INFORMATION-ARCHITECTURE-2026-09-27.md)之后说“你先试试”，本轮据此重写可操作样机。**仅为交互试验，未接入正式客户端，未获用户视觉验收。**

入口：[本地预览](http://127.0.0.1:4186/scenes.html) · [生成 HTML](../demo/scenes.html)。重新生成：`npm run build:scenes-demo`。

## 本轮结构

- 最左侧为窄图标功能栏：对话、私信、围炉、篝火、花园、书架、卷轴、工具库、通讯录、浏览器。常用小镇栏目直接进入。
- 旁边独立的场景列表只放聊天群，不随内容页面换成另一套目录。继续复用真实 `ChatSceneIndicator` 和场景管理操作。
- 主区域为同一个圆角阅读面：内容默认在左、当前群的对话在右。对话标题常显 Being、群名、信息入口。顶部没有小镇功能排。
- 换边只调整主面板位置。收起对话保留右下角 `Being · 当前群` 入口；纯对话没有能把主区域关空的按钮。
- 窄窗口沿用同一恢复入口切换内容和对话；场景列表按需浮出，选群后收起，固定列表不受影响。
- 设置只有左下角入口及同一快捷键页面，暂占内容区，关闭回原内容。Being 名称菜单中的自主醒来与设置使用同一个状态。

场景始终指聊天群；浏览、收起与换边不会创建另一个 Being。引用是明确选中的片段，不把所在内容页自动加入 Being 的上下文。

## 可操作的流程

| 操作 | 本轮结果 |
| --- | --- |
| 点固定功能图标 | 在内容区恢复该栏目上次位置；当前群、输入和引用不变 |
| 从工作讨论切日常聊天，再返回 | 恢复工作群的来信、聊天草稿、引用和已记录的阅读位置 |
| 划词 → 一起看 | 当前群草稿新增原文片段与来源；原有输入保留，不自动发送 |
| 私信旁讨论 → 放入回复草稿 | 同时保留主聊天和私信；若已有回复草稿，就地选择追加、替换或保留 |
| 收起／恢复对话 | 只隐藏／显示面板；恢复原群和草稿，收起后焦点落到恢复入口 |
| 内容与对话换边 | 两处输入与发送对象不变，组件不重建 |
| 工具详情 → 安装审阅 → 模拟安装 | 流程留在内容页，可中途离开；完成不抢走当前页面 |
| 安装结果 → 查看本机 → 返回安装来源 | 回到同一个工具详情和结果，不重新开启一轮安装 |
| 打开／关闭设置 | 当前聊天保留，关闭回原内容；纯聊天进入设置也能收起和恢复聊天 |
| 查看全部上下文 | 显示多群记录，明确提示当前发送目标；不改变 Being 或发送群 |

旧版的内容标签、整页“一起看”、浮动聊天、任意拼盘与“Being 安排”入口已撤出主流程。之前的探索文档仅作历史记录。

## 实现与数据边界

- 外壳和状态在 `desktop/renderer/workspace/`，示例业务在 `demo/scenes.tsx`、`demo/scenes-data.ts`。场景列表、CodeMirror 输入和 Markdown 渲染复用现有组件。
- 场景保存聊天草稿、引用、消息、阅读路径、栏目位置和离开视图时的滚动；私信回复草稿按源对象保存，跨群不会复制成两封信。
- 显示偏好单独保存；内容与聊天互换使用 CSS 排列，不调换数据。
- 新存储键为 `being-conversation-navigation-demo-v2`。迁移旧预览的草稿与消息，保留旧键；旧来源链接不伪造成实际划词内容。
- 所有消息、资料与安装都是示例。聊天发送只记入本地预览；私信、发言和安装不会对外执行。
- 设置、筛选、模拟安装和发送结果不跨刷新保存；滚动在离开视图时记录，未承诺刷新前最后一次滚动也完整持久化。
- 其他栏目提供入口和示例内容，**不是 73 项业务功能全部重构完成**。真实流式响应、权限、附件、队列、模型、连接、原生浏览器与安装事务仍需接入。
- 未打包、安装或替换日常客户端。旧源文件备份在 `.stash/scenes-before-ia-20260927/`。

## 本轮验证

- `npm run typecheck`、`npm run build:scenes-demo` 通过；13 条状态测试覆盖功能与群分离、场景恢复、共享回复草稿、收起边界、换边、安装往返、选区来源、发送快照和旧数据迁移。
- 在 1280 × 820 与 560 × 820 的浏览器窗口中操作检查导航、场景切换、私信建议冲突、安装往返、设置往返、收起恢复与窄窗列表。
- 实际鼠标拖选来信中的“最近想和你一起慢慢读点东西。”后点击“一起看”：只有该句进入引用，已有输入保持，消息条数未增加。
- 来信滚动到 91px 后换边、切到日常聊天再返回：滚动仍为 91px，聊天和回信草稿保留；最终页面浏览器日志无错误或警告。
- 浏览器验证发现并修正：纯聊天进入设置后无法收起对话；窄窗选群后临时列表仍遮挡内容。
- 以上通过只说明已验证的预览路径可用，不代表用户认可设计或真实 Electron 客户端验收。
