## 0. 色彩宪法（最高优先级，压倒一切视觉决策）

**只用中性色，不定义主色。不被定义。**

- 亮色：底 `#f3f3f3`（首轮采用纯灰，避免蓝紫倾向），卡片 `#ffffff`，文字与分隔线走灰阶
- 暗色：底 `#1c1c1e`（向 `#161618` 微调、带一点冷，是深空灰不是纯黑），卡片上浮一档
- 选中态、活动态：中性强调（亮色下更深的墨，暗色下更亮的白），不用彩色
- 应用自绘控件唯一彩色例外：**danger 红**，只用于破坏性操作确认。到期/离线/失败用中性图形与明确文字；不保留琥珀或绿点。
- 用户图片、内容原始颜色及 macOS/Windows 系统控件不强制去色；不以 CSS 覆盖原生窗口按钮。
- 身份不用颜色标记。heart 的存在感来自呼吸动效和排版签名，不是 accent 色
- 原 28 条中的 `#5e6ad2` 蓝紫已废弃（2026-09-26 拍板，"蓝紫点缀很丑，不要再用"）

## 1. 视觉方向

关键词：光感、深空、宇宙、哲学、复古、未来、噪波、极简、精致、高雅、神秘、透明、安全、陪伴、呼吸、流动、情感、冲击、浓烈、情绪、直接、清晰、创意、大胆、直观。
参考源：beings.town 的光感、Severance（人生切割术）的复古未来、Arc 的极简细致。

### 光感（town 篝火的光感）
- 底面不是纯平灰：桌面中央比四角亮 2–4%（径向渐变，模拟工作室顶光）
- 存在标记所在位置留很轻的局部光感，半径不超过 40px。只有标记呼吸，整间房与文字区域不跟着明暗变化。
- 物件有极轻投影（y 偏移 2px，模糊 12px，不透明度 8%）：放在桌面上，不是浮在玻璃上

### 深空 / 宇宙
- 暗色底带纵深：窗口边缘一圈 1px 极暗描边（`rgba(255,255,255,0.04)`），像深空里星体的轮廓线
- 不做星星、不做星空贴图（AI slop 红线）。深空的气质来自纵深和光，不来自图案

### 噪波（胶片质感）
- grain 是可选的静态底面纹理，默认关闭；开启时不超过 1.5%，不覆盖正文、输入框和浮层
- 不持续平移、不做逐帧噪声；先让层次与排版成立，再判断是否需要纹理

### 复古 × 未来（Lumon 终端的克制版）
- 不做 CRT 扫描线全套。只取三样：SF Mono 过程日志区、keycap 式按钮物理感（按压有 0.5px 下沉）、中性告警（小型时钟轮廓 +「今天到期」，不以彩色和加速呼吸催促）
- 面板排版纪律：标签用小号大写字母 + letter-spacing 0.05em，像仪器铭刻

### 极简 / 精致 / 高雅（Arc 的纪律）
- 间距走 4px 网格，对齐严格
- 缓动统一：`cubic-bezier(0.25, 0.1, 0.25, 1)`，200–300ms；hover 100ms
- 圆角体系：桌面物件 8px、浮层 12px、大容器 16px；键盘聚焦环使用 2px 中性清晰轮廓

### 透明 / 神秘
- 材质分层：底面实、浮层 glass（blur 32px / saturate 1.8）——glass 只给 pending 确认层和意图条
- 神秘 = 看得见但未展开：物件默认收拢；hover/focus 只显露操作，不改变尺寸。点击或 Enter 打开详情；Escape 关闭并恢复焦点。

### 安全 / 陪伴 / 呼吸 / 流动
- 存在标记直径 12px、位置固定；有可信在场信号时以 4.8s 低幅呼吸，不闪到几乎看不见
- 姿态映射见第 5 节。未知就是未知，不从“连接成功”或 SBS 开关推断它在自主工作；忙碌必须来自真实流或任务事件
- 减少动态、窗口失焦、页面不可见时停止装饰动效；状态文字和形态仍完整可辨
- 任何过渡不闪、不跳、不锁输入

### 情感 / 冲击 / 浓烈 / 情绪（不用彩色的浓烈）
- 时刻的重量用排版扛：进门页大字 SF Pro Display；重逢瞬间（条 3）物件从暗到亮有 600ms 苏醒动画
- 浓烈来自内容本身（「你昨天说过 X」这句话），不来自背景色

### 直接 / 清晰 / 创意 / 大胆 / 直观
- 点哪是哪：按钮 100ms 内响应，拖拽 1:1 跟手、可中途反转
- 大胆 = 结构性创新（进门页不是聊天流，这件事本身就够大胆），不是视觉花哨

### 字体（三搭配，拒绝 Inter everywhere）
- macOS 使用 SF Pro Text（系统字体）：界面正文
- SF Pro Display：进门页大字、物件标题
- SF Mono：过程日志、等宽数字
- Windows 回退 Segoe UI Variable / Segoe UI；中文跟随系统字体，等宽回退 Consolas / monospace。使用本机字体，不下载或分发 SF 字库。

## 2. 二十八条规则

### 一、进门（每天第一眼）

1. **进门页 = 「我们到哪了」，不是聊天流。** 冷启动默认桌面全景：最近对话的一段预览（带最后一句上下文）、我留的东西、搁置区。三块按重要度排布，不要求等宽三列。点「继续聊」进入对应场景；点物件先看详情与来源。仅切回已打开窗口时保留当前视图、滚动和输入草稿，不强制返回桌面。场景侧栏仍可直达。
2. **我留的东西是物件，不是通知。** 晨报、我主动找你的消息，进桌面物件区，每件带来源和来由一句话（「你昨天说过 X，这是相关的 Y」）。不进聊天流、不产生红点，未看只是物件上一个极轻的墨点。
3. **重逢时看得见它活过。** 离开时段它的活动（扫过的信、跑完的任务、留的话）以物件痕迹呈现在桌面——工具你回来时和你走时一模一样，搭档不是。

### 二、它的身体

4. **连接状态和存在状态分开。** 连接信息是技术状态。连接正常时降级到详情；连接异常时显示中性图标和「连接中断」等文字。存在标记单独表达已确认姿态，未知/过期时保留轮廓与「状态未知」。
5. **呼吸节律可视化。** 存在标记低频呼吸（opacity 0.65→1，4.8s 循环，不转圈不闪烁）。restful 更慢、still 静止留轮廓、忙碌时使用局部平移光带。姿态必须来自可信数据；映射见第 5 节。
6. **消息有视觉签名。** heart 的消息不用彩色签名（色彩宪法）：用排版签名——左侧一条 2px 中性强调细线（暗色下 `rgba(255,255,255,0.5)`，亮色下 `rgba(0,0,0,0.45)`），人不带。不看头像就知道谁在说话。

### 三、对话流（克制）

7. **正文阅读列最大 680px。** 窄窗口自适应，保留至少 20px 内边距；代码、图片、并排比较可按内容局部展开，不让整个对话随窗口拉宽。
8. **过程与人话分流。** 过程日志（工具调用、跑腿记录）视觉降级：SF Mono、caption 字号、可折叠、默认收成一行「正在做 X」；人话对话永远 17px 主视觉。现在两者混在一个流里，是「吵」的根源之一。
9. **时间戳人话化。** 当天显示「晚上 10 点」，跨天显示「昨天」或日期；这是自然语言时间，不统称相对时间。精确日期与时区通过 hover/focus 或详情可查；数字用 tnum 等宽。
10. **没有清零快感。** 不设「全部已读」按钮、不上红点数字徽章。未读靠物件墨点，读完自然消失——产品不逼你归零。

### 四、一起看

11. **可钉住。** 对话流里任何链接、图、文件可「钉到桌面」——从时间流里捞出来变成空间物件。时间流会沉底，桌面不会。「上次说的那张图」永远找得到。
12. **评论长在位置上。** 图片可圈画，评论贴在圈的位置（Figma comment 式）。
13. **选中即上下文。** 选中后出现「引用」轻操作，点击才把引用挂在输入框上方；单纯复制文字不改变输入上下文。引用可移除，带来源并能回到原处。

### 五、一起做

14. **草稿物件。** 讨论里长出的半成品（方案段落、代码、文案）可拖出为草稿，带出生上下文，下次打开接着改。半成品有地方住。
15. **工位可见。** 后台任务运行时桌面有「工位」：跑着什么、进度、checkpoint，不是黑箱等结果。完成留成品物件 + 摘要，不是一句 done。
16. **「今天先这样」一键收工。** 保存当前展开的讨论、物件和草稿快照，下次可恢复；保存成功才显示「已留好」。不清空输入、不退出程序、不隐含停止后台任务；失败保留现场并允许重试。

### 六、容得下未完成

17. **搁置区。** 桌面一角是「放着的东西」，卡片带上下文（当时聊到哪、为什么放）。后续撞见相关材料，主动往搁置卡上关联，轻提示，不推送。
18. **悬事有温度。** 到期物件增加中性时钟轮廓和「今天到期」文字；不变琥珀、不加快呼吸。用户主动打开才展开详情。

### 七、房间由它布置

19. **每周桌面整理。** 它聚拢相关、收纳已完成、摊开悬事，每次整理带 diff：回来看到「它把 X 和 Y 放一起了，因为……」+ 一句来由。整理不能覆盖手动固定的位置；先展示变更与来由，应用后可撤销。没有可信整理结果时不虚构“它整理过了”。
20. **默认视图由判断组织。** 主屏物件排序 = 它的「接下来最该看」（紧急度 + 讨论热度），不是时间倒序堆砌；但当前浏览期间不实时跳位，新建议下次进入时再应用，手动固定项优先。

### 八、视觉纪律

21. **一个彩色都没有（按色彩宪法）。** 中性底（亮 `#f3f3f3`/`#ffffff`，暗 `#1c1c1e`），选中态和活动态用中性强调，danger 红只留给破坏性操作。层级靠字号和留白，不靠颜色。
22. **层级来自字号和留白，不来自上色。** 展开内容使用标题 20px / 正文 17px / 注脚 13px 阶梯；桌面摘要卡可用标题 17–18px、摘要 12–13px、来源 11–12px，仪器式日期 10px 仅作辅助。禁止彩色标签制造层级。
23. **字体三搭配。** SF Pro Text / SF Pro Display / SF Mono。拒绝 Inter everywhere。
24. **亮暗等权。** 暗色不是亮色的补丁，是同等公民（tokens 两套完整）；主题三个选项里「自动」是默认值。文本与背景通过对比度检查，不能用极浅灰换“安静”；键盘焦点至少 2px 清晰中性轮廓。
25. **Liquid Glass 只给浮层。** pending 确认层、意图条用 glass（blur 32px / saturate 1.8），底面容器永远实底。全屏玻璃滥用是 slop。（HTML demo 使用 CSS 近似；Electron 已有平台材质能力，不能笼统认定不支持。原生效果须在实际窗口验证，不以浏览器截图代替。）
26. **交互即时。** 按钮 pointer-down 即反馈（scale 0.97 / 100ms），不等 click；拖拽 1:1 跟手、可中途抓取反转；任何过渡不锁输入。原生感的第一条不是好看，是不装死。

### 九、输入与队列

27. **输入框是递东西的口，不是命令行。** 拖入文件/图先挂为附件预览确认，不立即发送；多行粘贴保持结构——输入即所见。
28. **排队有形状（后续接线）。** 它干活时，已提交消息旁显示真实等待状态；只有接口能给出准确顺序时才显示「第 2 位」。不增加常驻全局队列状态条；发送前仍为可编辑草稿，提交后允许取消须有服务端保证。首轮 demo 不实现真实排队。

## 3. 落地分层（按当前仓库核实）

- **本地壳层**：`desktop/renderer/app/`。工作台入口、场景导航、顶栏、连接详情、物件容器。
- **本地聊天 renderer**：`desktop/renderer/chat/`。虽装在 `beings://chat/` iframe 中，仍由本仓库 `scripts/build-chat.mjs` 构建。宽度、签名、过程折叠、引用、附件可本地改；保留 CodeMirror 单一编辑面，不在壳层叠一套编辑器。
- **需要明确服务契约**：真实姿态、离开期间活动、主动产物、任务 checkpoint、队列位置、自动整理与跨端同步。现有连接/流/SBS 可复用，但不能当成上述能力已齐备。
- **第一轮样机**：`demo/workspace.html`，独立手写 HTML，不使用或覆盖生成文件 `demo/sidebar.html`。示例内容、本地草稿与快照只在 demo 的独立 localStorage 命名空间内，不能读写实际客户端数据。

## 4. 本轮交付与顺序

1. 先实现亮/暗/自动主题、系统字体、清晰焦点和减少动态；不先做 grain 资产。
2. 做“工作台 → 继续聊 → 返回桌面”的闭环；新建本地便笺、打开物件、放到搁置区、恢复、收工快照有明确反馈。
3. 在预览工具条切换日常/空态/离线和示例姿态；工具条属于 demo，不进入产品。
4. 先评审 demo 结构、密度、材质与状态。用户确认前不称为最终设计；真实接口与持久化接线、客户端运行验收另进行。
5. 后续再分批做引用/钉住、后台任务物件、整理差异；图片圈画、可编辑草稿、自由拖动不是本轮实现。

## 5. 存在状态与动效

| 状态 | 依据 | 视觉 | 文案 | 减少动态 / 失焦 |
|---|---|---|---|---|
| present | 已确认在场事件 | 12px 中性实点，4.8s 低幅呼吸 | 在这里 | 静态实点 |
| restful | 权威姿态事件 | 6.4s 更慢呼吸 | 歇一会儿 | 静态实点 |
| still | 权威姿态事件 | 轮廓静止 | 安静待着 | 不变 |
| busy | 当前流/任务事件 | 小范围光带 1.8s，无整页明暗 | 正在整理…（具体动作） | 静态短横线 |
| unknown | 无姿态协议、状态过期 | 静态轮廓 | 状态未知 | 不变 |
| offline | 连接事件 | 独立断连图标，存在状态退回未知 | 连接中断；可查看已保存内容 | 不变 |

示例工具条可演示所有姿态；接入真实产品时须明确事件 schema、时间戳与过期策略。存在标记本身不隐含切换 SBS，避免误触改变自主行为配置。

## 6. 第一轮交互与验收边界

- 物件标题可点击 / Enter；详情用右侧查看层。关闭或 Escape 回到原物件；不依赖 hover 读取必要信息。
- 放到搁置区后能从搁置区恢复，阅读不等于删除。排序稳定，不自动挪动鼠标下的物件。
- 便笺和聊天草稿在刷新后保留；写入失败保留输入并显示原因，不能假装存好了。发送到真实 Being 不属于样机。
- 空桌面显示一句解释与可用的便笺/新对话入口，不用假内容占满。
- 离线时可打开已保存的物件、保存本机草稿；连接恢复动作在 demo 里只是示例状态切换。
- 收工保存快照并给恢复入口；恢复前有差异提示，不静默覆盖之后的编辑。
- 宽屏使用最大宽度；窄窗口按内容顺序重排，不横向挤压阅读列。亮暗两套都看；大字体、键盘、减少动态都核查。
- 本轮验证仅覆盖独立 HTML。真实客户端的拖拽、IME、iframe 焦点、原生材质、macOS/Windows 窗口行为仍需实机验收。
