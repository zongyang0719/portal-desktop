> 历史迭代记录。当前设计唯一依据：[IA-REFACTOR-SPEC-2026-09-27.md](IA-REFACTOR-SPEC-2026-09-27.md)；当前实现见 [实施记录](IA-REFACTOR-IMPLEMENTATION-2026-09-27.md)。

日期：2026-09-27。用户已确认左中右结构及按层级重构；本轮执行于 mine，保留未提交工作，不提交或安装第二个客户端。

**Goal:** 左栏组织场景和小镇，中间持续与同一个 Being 对话，右侧负责阅读、详情及操作。

**Architecture:** 沿用 Electron、React、聊天 iframe 与已有场景管理。将小镇分类提取为共享导航定义，扩展现有侧栏的组合接口；对话发送场景与右侧位置独立。右侧按栏目记住阅读现场，浏览器占用同一右侧区域。

**Tech Stack:** React / TypeScript / CSS / Electron；Vitest 行为回归与真实组件 HTML 预览。

## 行为接口与验证

```ts
type PlaceGroup = 'social' | 'reading' | 'tools';
// openPlaceGroup(group) 只打开右侧，不更改当前聊天。
// Town 的 remember/restore 按身份 generation 保存阅读快照，换身份清空。
// revealBrowser() / hideBrowser() 只改变右侧展示，不销毁聊天或 Town 草稿。
```

核心用例：已有主草稿时依次打开私信、卷轴、工具库，再返回私信，主草稿及原私信筛选保留；切换聊天场景不换 Being、不关闭右侧；配对身份改变后不能恢复旧私有阅读；收起浏览器不再产生第四栏。安装仍使用原接口，不以模拟成功表示真实工具可用。

本轮沿用 native-feel 的 T3 平台习惯和 T7 操作记忆原则，保留 CodeMirror、原生文件操作和已有快捷键；不更换运行架构。实际接口未支持的存在状态、记忆编辑、暂停恢复与物件存储不在界面中假造。

## 本轮落地结果

本轮完成导航骨架和核心往返流程，尚不是全量 73 个界面单元的视觉验收。功能总表仍以 `ux-audit-desktop-full-2026-09-27.md` 为准。

- 左栏复用真实场景组件，新建、绑定、排序、多选与信息入口保留。Being 名称取主对话配置；Town 名称取配对身份，Portal 和自主醒来各自保留状态。
- 小镇按交流／阅读／工具库组织；右栏再选栏目。目录与详情在窄内容区内逐层打开，进入详情后收起列表筛选、页码。宽阅读模式可以同时看目录和详情。
- 每个栏目保存筛选、页码、选中内容与滚动；正在加载或失败的读取不缓存为完成页面。Town 身份变化清空旧阅读和旧私信草稿。
- 回复在右栏编辑，主对话仍可用；正文和委托要求分开。普通发送只使用正文。跨收件对象的正文与要求分别暂存，范围是当前客户端会话，并不承诺重启恢复。
- 内置浏览器与 Town 阅读互斥占据右侧。收起网页保留原生 WebContents 和历史；只有明确打开请求重新显示浏览器，后台加载事件不会抢回面板。
- Kit 安装完成保留来源，查看本机 Kit 后有“返回安装来源”和“返回本机工具列表”两个明确去向。
- 场景信息按钮常驻；中间与右侧采用轻描边圆角阅读面，底部不再重复铺开小镇菜单。
