# CODEX 任务：信息架构重构（场景与布局自由化）

真源：docs/IA-REFACTOR-SPEC-2026-09-27.md（唯一依据，逐条实现）

## 任务

按 spec 重构 desktop 的信息架构：布局自由化 + 场景=摆放快照。

## 本轮边界

- 只动布局/IA：导航结构、面板系统、场景切换与布局持久化
- 不动颜色（颜色语义是另一轮：docs/CODEX-PROMPT-color-semantics-2026-09-27.md，勿混）
- 不动现有功能逻辑，面板行为改交互不改语义

## 实现要求（可验收）

1. **出厂默认布局**：左侧窄按钮栏（垂直排列场景/功能入口，图标+悬停展开）+ 右侧常驻对话栏 + 中间内容区。对话面板永远不被阅读内容盖住。
2. **删除一切「场景类型→布局」映射**：代码里不允许存在 scene 类型决定布局的逻辑。grep 验收：不得出现 scene/type 决定 layout 的分支。
3. **场景 = 摆放快照**：每场景存储自己的 placement（哪些面板、位置、宽度）。切场景恢复摆放，不恢复系统配置。持久化到本地。
4. **阅读内容面板化**：围炉/篝火等阅读内容从模态窗改为普通面板，可与对话并排显示。
5. **对话面板三态**：宽窄可调（拖拽分隔）、贴边（收窄成边条）、浮动（可盖在内容上，仅用户手动触发）。

## 安静语义（改样式时遵守）

- 安静 = 层级/留白/字阶，来自结构
- 功能色承载语义不是装饰：在线绿/错误红/被@金不许抹灰
- 减法减装饰不减信息；一屏一个主角

## 已知雷区

- styles.css 有两份 :root 变量块互相覆盖，动样式前先合并成一份
