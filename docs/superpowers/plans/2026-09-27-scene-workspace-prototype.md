# 场景组合样机

执行范围：在 `mine` 新增可离线打开的组件样机，保留已有方案，不接真实发送、安装与账号接口。用户已要求先做，不增加设计确认环节。

依据：`docs/UIUX-SCENE-PRESENTATION-2026-09-27.md`。借鉴 Arc 的场景与内容分层、Linear 的临时查看、VS Code 的内容组合；同一个 Being 贯穿所有呈现。

1. 新建独立的场景呈现状态与共享外壳。场景保存标签、排列、输入和阅读位置；内容身份不随面板变化。
2. 用示例适配器打通私信与讨论、两份资料比较、浮动讨论、设置返回、工具安装后返回。Being 安排是明确的演示动作。
3. 验证切场景、保护正在编辑的内容、恢复排列不撤销草稿、发送捕获场景与引用等状态边界。
4. 生成 `demo/scenes.html`，在浏览器检查视觉与实际操作，记录已实现与尚未接入的边界。独立浏览器页面不冒充 Electron 系统浮窗。

不自动提交、打包或替换日常客户端。样机反馈后再接入真实页面。
