## 重写后的首屏

- 顶部只有场景入口、当前场景名称、存在标记和更多。
- 中间只放上次讨论的一段内容与「继续聊」。不并排展示活动痕迹、物件卡片和搁置区。
- 底部用一行打开物件；输入框只用一条分隔线界定。
- 场景列表与物件列表按需展开。示例状态、主题选择、收工快照都收进更多菜单。
- 平底、系统字体、中性灰阶；没有 grain、光晕、全页呼吸和进入动画。存在标记保留局部低幅呼吸，减少动态与失焦时暂停。

## 组件版（按用户要求沿用 sidebar HTML 方式）

- `scripts/build-component-demo.mjs` 为两个预览共用的单文件构建器，内联 JS/CSS 并自动收集打包依赖的许可证。原 sidebar 命令与入口保留，另加 `build:workspace-demo` / `workspace:watch`。
- 工作台主体位于 `desktop/renderer/app/components/workspace-home.tsx`，数据和模拟操作位于 `demo/workspace.tsx` / `workspace-state.ts`；共享正式 `ChatSceneIndicator`、CodeMirror `ComposerField`、`Dialog`。没有把手写 HTML 嵌进 React。
- `ChatSceneIndicator` 新增可选 heading/footer 插槽与初始展开参数；既有调用保持默认行为。`useSidebarPeek` 仅新增可选初始参数。原客户端的 `workspace.tsx` 保持原样；新组件尚未接入生产页面。
- 按 v2.2 移除首屏物件入口，补真正受未读状态控制的一行示例消息；物件限当前场景，搁置/收件入口位于侧栏，存在标记移到输入旁。未知/离线静止，失败保留原因，streaming 只由手动示例事件触发一次脉动。
- 旧 localStorage 只读导入 v3 新 key，保留草稿、物件、未提交便笺和收工快照。编辑过程中关闭浮层不会丢草稿；从导航删除的场景仍可从搁置入口拿回。
- 已通过两个 HTML 的构建、全仓 `tsc --noEmit`、5 项存储迁移/恢复测试及 3 项既有编辑器 Markdown 测试。
- 浏览器访问本机预览被自动审批拒绝；用户回复「可以」后再次访问仍被拒绝。因此本轮未运行浏览器交互/截图验证，也未运行会启动其他浏览器的测试来绕过限制。375px/1440px、明暗视觉、真实 IME 和 Electron 验收均待完成。
